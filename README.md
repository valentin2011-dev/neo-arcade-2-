# NEO ARCADE — V1 + V2

Mini-arcade futuriste installable (PWA), réunissant les jeux classiques et les nouveautés V2.

### Jeux
REACTION · MEMORY · NUMBER RUSH · NEON SNAKE · NEON AIM · BATTLE LOCAL

### Fonctionnalités
XP, niveaux, succès, records locaux, 10 avatars, 10 thèmes, effets RGB et fond d'écran personnalisé.

**Installation :** héberger en HTTPS, ouvrir une première fois en ligne puis installer depuis le navigateur. Les données sont locales à chaque appareil.

**À venir :** Battle en ligne, classement mondial et synchronisation cloud validée.
